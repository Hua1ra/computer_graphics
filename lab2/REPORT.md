# Лабораторная работа 2, вариант 4

Темы: построение и эквализация гистограммы + линейное контрастирование; сегментация (точки, линии, перепады яркости).
Запуск: `python make_test_images.py` (создаёт `test_images/`), затем `python app.py`. Нужны numpy, pillow, matplotlib, tkinter.

## 1. Повышение контраста

**Линейное контрастирование:** `out = (in − min)·255 / (max − min)`. Диапазон яркостей растягивается до [0, 255], форма гистограммы не меняется. Метод не помогает, если в изображении уже есть и чёрные, и белые пиксели, и чувствителен к одиночным выбросам.

**Эквализация гистограммы:** яркости преобразуются функцией `T(k) = (cdf(k) − cdf_min)/(N − cdf_min)·255`, где cdf — накопленная гистограмма. Часто встречающиеся уровни разводятся шире, гистограмма становится более равномерной.

**Сравнение (изображения 01, 02, 04, 05; СКО яркости: исходное → линейное / эквализация RGB / эквализация HSV):**
- 01: 5.7 → 32.0 / 60.9 / 61.4
- 02: 6.4 → 31.8 / 60.8 / 48.6
- 04: 7.4 → 24.1 / 59.2 / 62.5
- 05: 7.2 → 23.6 / 61.0 / 56.3

Эквализация даёт больший контраст, чем линейное растяжение, потому что перераспределяет уровни, а не только растягивает диапазон. На зашумлённом 04 эквализация сильно усиливает шум (разглаженные участки получают разный уровень), линейное контрастирование — слабее.

**Два подхода для цветных изображений.**
- *RGB:* каждый канал выравнивается независимо, соотношение R:G:B меняется, цвета искажаются. На 05 (сильный цветовой перекос) средние значения каналов были (100, 104, 78) → после RGB-эквализации (98, 142, 153): красный стал самым слабым, синий — сильным, цветовая гамма изменилась.
- *HSV (только V):* тон H и насыщенность S не меняются, выравнивается только яркость; средние (142, 147, 109) сохраняют исходное соотношение каналов (красный ≈ зелёный > синий), цвета остаются прежними.

Вывод: если важна цветопередача, используют выравнивание яркости в HSV; RGB-эквализация подходит, когда нужно заодно убрать цветовой перекос.

## 2. Сегментация

Свёртка 3×3 с отражением краёв. Для линий и точек результат — бинарное изображение по порогу, заданному долей максимально возможного отклика.

**Точки.** Маска `[-1 -1 -1; -1 8 -1; -1 -1 -1]` (сумма коэффициентов 0 — на однородном фоне отклик 0). Точка отмечается при `|R| ≥ T`. На 10_points при T = 0.4 найдены все 40 вставленных точек (светлые и тёмные). Метод чувствителен к шуму: шумовые выбросы тоже дают большой отклик.

**Линии.** Четыре маски 3×3 (горизонталь, вертикаль, +45°, −45°), каждая реагирует на линию толщиной 1 пиксель своего направления. Режим «все направления» берёт максимальный отклик из четырёх. На 11_lines горизонтальная маска выделяет 1681 пиксель, вертикальная — 1021, +45° — 285, −45° — 325 (каждая — только линии своего направления плюс небольшие «хвосты» от других).

**Перепады яркости.** Собель и Превитт — первая производная (модуль градиента), содержат сглаживание поперёк направления производной; Лапласиан — вторая производная, направление не определяет и сильнее реагирует на шум. Средняя яркость карты границ на чистом 12_edges: Собель 4.0, Превитт 4.0, Лапласиан 2.7; на зашумлённом 13_edges_noisy: 31.8, 30.6, 43.7 — у Лапласиана шум забивает карту сильнее всего.
